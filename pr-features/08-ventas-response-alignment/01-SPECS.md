# Feature 08: Ventas Response Alignment

## Objetivo

Dejar documentado que los consumidores actuales de `ventas/` siguen usando contrato legacy plano y que el backend nuevo ya debe responder bajo ese formato en los flujos activos de pagos y carga de producto.

## Alcance

- Flujos de pagos POS
- Flujos de cuentas por cobrar
- Flujos de cuentas por pagar
- Carga de producto a documento activo

## Resultado esperado

- El frontend puede seguir consumiendo `ventas/` sin cambios estructurales adicionales.
- Solo quedan pendientes pruebas funcionales manuales sobre la aplicación.
