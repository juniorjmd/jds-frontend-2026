# Acceptance Criteria

- abrir caja consume `response.data.message` y `response.data.box`
- cerrar caja consume `response.data.summary`
- cerrar caja parcial consume `response.data.summary`
- resumen de caja consume `response.data.summary`
- errores se muestran desde `error.message` del envelope estandar
- existe test del servicio de caja para el desempaquetado del contrato
